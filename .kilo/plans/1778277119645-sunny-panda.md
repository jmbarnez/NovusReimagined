# Plan to Fix Targeting Issues

## Task Description
Fix two targeting issues:
1. Add lock square rendering for salvageable debris (wreck pieces).
2. Auto-assign the selected turret to newly locked targets if valid.

## Analysis
- Lock squares are drawn in `src/render/world.ts` for asteroids and enemies when locked and resolved.
- Wreck pieces can be locked but lack lock square rendering in `drawWreckPieces`.
- Wrecks can also be locked but lack rendering in `drawWrecks`.
- Turret auto-assignment currently only happens for special turrets (mining/salvager) in `tryAutoAssignSpecialTurret`.
- For regular weapon turrets, auto-assign to selected turret when locking on enemies if valid.

## Steps
1. In `src/render/world.ts`:
   - In `drawWrecks`, add lockMap creation and lock bracket drawing similar to asteroids.
   - In `drawWreckPieces`, add lock bracket drawing similar to enemies.

2. In `src/targeting.ts`, in `updateSensorLocks`, after `tryAutoAssignSpecialTurret`, add logic to auto-assign the selected turret for enemies:
   - Check if target is enemy, selected turret is weapon turret, powered, no cooldown, no existing target.
   - Assign and play sfx.

## Validation
- Lock on wreck pieces and wrecks: lock squares should appear.
- Lock on enemies: selected weapon turret should auto-assign if available.
- Existing auto-assign for mining/salvager on asteroids/pieces remains.
