# Camera Shake / Rubber Banding Plan

## Root Cause
The camera exhibits constant micro-shake/rubber-banding (even when the ship is stationary) because of double smoothing:

1. `src/utils/camera.ts:9-14` runs every fixed physics tick (60 Hz):
   ```ts
   Client.pcamx = Client.camx;
   Client.pcamy = Client.camy;
   const lag = Client.settings?.cameraSmoothing ?? 0.08;
   Client.camx = lerp(Client.camx, G.P.x, lag);
   Client.camy = lerp(Client.camy, G.P.y, lag);
   ```
2. Rendering (`src/game-loop.ts:112-113`) then does a second interpolation:
   ```ts
   const camxR = lerp(Client.pcamx, Client.camx, alpha);
   const camyR = lerp(Client.pcamy, Client.camy, alpha);
   ```

This combination of lagged follow inside the physics step + render-time interpolation creates visible oscillation, especially noticeable at rest or low speeds.

## Solution
Remove the lagged camera update from the physics tick. Compute the rendered camera position purely at render time by lerping the previous camera directly toward the player's current position using the existing `alpha` value. This eliminates the double lerp while preserving smooth camera motion.

## Implementation Steps
1. Delete or empty the body of `updateCamera` in `src/utils/camera.ts` (or remove the call entirely).
2. In `src/game-loop.ts` (render path), replace the current camera interpolation with a single smoothed follow:
   ```ts
   const lag = Client.settings?.cameraSmoothing ?? 0.08;
   const camxR = lerp(Client.camx, G.P.x, lag * alpha); // or similar scaled approach
   const camyR = lerp(Client.camy, G.P.y, lag * alpha);
   ```
   (Exact scaling of lag by alpha may be tuned; the key is one lerp only.)
3. Update `Client.pcamx / pcamy` only when needed for other systems, or remove if unused after the change.
4. Verify no other code paths still rely on the old `updateCamera` behavior.
5. Run `npm run check` and `npm run lint` to confirm no breakage.

## Expected Outcome
Camera becomes stable with no rubber-banding when stationary or moving; existing `cameraSmoothing` setting continues to control feel.
