# Eliminate Remaining Camera Jitter / Shake When Stationary

## Current State After First Fix
- Double-lerp removed; smoothing now single lerp(Client.camx, G.P.x, lag * alpha) + persist in render path (game-loop.ts:112-117).
- Camera follows more stably, but user reports occasional "jerks" even when ship is completely still.

## Root Cause of Residual Jitter
Physics integration (ship.ts:128-130) applies drag *= drag each tick; when thrusting stops, velocity decays exponentially but never reaches exact mathematical zero due to floating-point precision. Tiny residual `vx/vy` cause `G.P.x/y` to change by sub-pixel amounts every few frames. The lerp in render then produces a visible micro-step because `lerp` has no dead-zone and `lag*alpha` is always >0.

No explicit "at rest" detection or camera dead-zone exists.

## Solution
Add a small positional dead-zone (e.g. 0.05 world units) in the camera follow logic: when the camera is already within the threshold of the player's position, snap `camx/camy` directly to `G.P.x/y` instead of lerping. This guarantees pixel-perfect stability once the ship has come to rest while preserving smooth motion when moving.

## Implementation Steps
1. In `src/game-loop.ts` render block, replace the camera smoothing block with a dead-zone guarded version:
   ```ts
   const lag = Client.settings?.cameraSmoothing ?? 0.08;
   const dx = G.P.x - Client.camx;
   const dy = G.P.y - Client.camy;
   let camxR, camyR;
   if (Math.hypot(dx, dy) < 0.05) {
     camxR = G.P.x;
     camyR = G.P.y;
   } else {
     camxR = lerp(Client.camx, G.P.x, lag * alpha);
     camyR = lerp(Client.camy, G.P.y, lag * alpha);
   }
   Client.camx = camxR;
   Client.camy = camyR;
   ```
   (0.05 is a suggested starting value; tune if needed for visual feel.)

2. Optionally remove now-unused `pcamx/pcamy` fields from `Client` in `src/state.ts` and their initializers (cleanup only; not required for functionality).

3. Verify the change eliminates all visible camera movement when `speed === 0` and player is not thrusting.

4. Run `npm run check` and `npm run lint`.

## Expected Outcome
- Zero camera motion or jerk when ship is stationary (no input, velocity decayed).
- `cameraSmoothing` slider continues to affect motion feel when actively moving or turning.
- No other side-effects on HUD, targeting, or world rendering.
